## 4. AML routing

- 7 transactions fired an AML reason code (AML-001 / AML-002).
- **7/7 routed to human review (100.0%).**
- **0 auto-declined. 0 approved.**
- 4 of them reached the agent band only because of the AML override -- their raw score alone would have auto-approved or auto-declined them.

The guarantee is enforced deterministically in `engine/fallback.enforce_policy`, off the reason codes the *rules* fired, never off the codes the model chose to return. During development the agent legitimately dropped a code it believed it had explained away; a guardrail that reads the model's own output would have let that through.
